# Atmosphere2D · 可复用2D氛围 v1

这是独立 Godot 工程和可复制组件，不依赖个人活动、剧情状态或原型存档。当前是可运行灰盒，不是正式美术场景；独立游玩与第二工程复用验收尚未全部完成。

## 打开与游玩

用 Godot 4.7.2 打开本目录 `project.godot`，运行主场景 `demo/main.tscn`。不需插件安装、联网或付费服务。兼容渲染器，1280×800。

- WASD / 方向键移动；靠近箱子按 E 拿起，再按 E 放下。
- 靠近门洞按 E 开关门；固定墙不会随门消失，占位时拒绝关门。
- 顶部按钮切换晴日、阴雨、雪日、晴夜、雨夜雾、雪夜雾。
- 高 / 低 / 关闭用于质量与原图对照；灯按钮切换局部灯，区域调试显示覆盖范围。
- 从庭院走到屋檐，再经唯一门洞进屋；可以搬箱通过门洞。湿雪网格固定在地面，不随观察者进屋整体消失。

现有游玩 MCP 已增加固定白名单入口 `atmosphere-demo`：`catalog {}` → `launch {"project":"atmosphere-demo","headless":false}` → `observe` / 普通 `action` → `stop`。按 [公共游玩说明](../../../tools/play_mcp/README.md) 调用；不接受任意项目路径。运行中的旧 stdio 服务需要由其所有者正常重新启动才会读取新目录，本包不会自动重启宿主服务。开发者有限启动/移动/晴日按钮 smoke 已记录，独立玩家完整体验仍待交。

## 在自己的项目复用

只复制 `addon/`，不必复制 demo、探针或个人活动。最小构造与完整接口见 [组件说明](addon/README.md)。世界图像/几何应在同一 lit canvas，UI/文字放另一个 CanvasLayer。CanvasModulate 调整整个 canvas，并非仅影响 world 节点子树。

组件提供环境光平滑变化、雨雪风与二维软雾、独立降水覆盖区、PointLight2D、地表湿雪采样、音频混合插槽和质量/关闭档。光遮挡轮廓由宿主显式创建 LightOccluder2D；挡雨区不自动成为挡光墙。组件不修改移动、碰撞、剧情或存档。

## v1 的准确边界

- 普通 PNG 可直接受环境光和局部光；不要求法线贴图。unshaded 材质例外。
- 室内 ambient 是观察者位置驱动的全 canvas 适应，不是每像素分区照明。
- 雨雪为即时点线，雾为缓慢漂移的径向软簇，不是体积散射；区域边缘可能有软簇溢色。
- 湿雪网格是地表采样消费示例，不是湿反射或积雪物理。接触影由 demo 示范，组件不自动追踪人物。
- 音频接口可接合法 AudioStream，但包内没有现成音源。没有雷电/频闪、联网天气、自动图像语义或收费依赖。
- 关闭恢复、冻结、同 id 更新、显式注销及 dispose 有有限引擎自测；实际视觉品质和独立接入验收不能用自测数量代替。

[执行清单](manifest.md) 保留各阶段失败与日志引用，其中本机 Temp 路径仅是开发证据，不是运行依赖。不要把开发机器路径、日志、缓存或存档作为分发前提。
