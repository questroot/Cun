# Atmosphere2D v1 · 交付与验证边界

## 分发文件

- `addon/atmosphere.gd` 与 `addon/README.md`：可复制组件、API 与能力限制。
- `project.godot`、`demo/main.tscn`、`demo/main.gd`：独立空间灰盒。
- 开发用空间、组件与退出探针保留于开发工作区，不作为公共运行包分发；本清单提到的探针文件名属于历史证据索引，不是 clone 后必须具备的文件。早期 `demo/probe.gd` 的部分断言针对旧布局，**不是当前整合演示的全量验收入口**。
- `scripts/ai_play_bridge.gd`：与公共游玩桥同源，只有配置合法 loopback 环境变量时监听。

不分发引擎裸 exe、缓存、日志、测试存档或开发机器绝对路径。运行不依赖开发者的 Temp 证据目录。当前验收尚未全部完成。

## 已实现及简化边界

五固定API、时间/事件环境光过渡、普通PNG和几何统一受光、PointLight2D、独立雨雪覆盖区、风和二维软雾、地表湿雪数值、可选音频混合、高低关闭与冻结、同id更新和dispose。光遮挡由宿主显式提供，区域 ambient 为观察者驱动的全canvas适应。演示有固定墙/门洞/门叶、拿放箱、固定地面湿雪采样与接触影示例。

没有法线/湿反射shader、真实体积雾、动态积雪物理、自动遮挡生成、自动人物阴影注册、现成音源或正式美术。雨雪为即时绘制，软雾边缘可能溢色；地面格为诊断反馈。具体 API 与约束以 [组件说明](addon/README.md) 为准。
