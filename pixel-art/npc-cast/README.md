# NPC 静态像素人物图集

2026-10-21 本地绘制。按当前福地代码五位剧情人物，加主城向导及已确认的商人，共7人。人物身份与道具取自现有地图对白；年龄、发型、服装及拾一的机偶外观为本轮美术设计候选。

| 人物 | 文件名 | 识别设计 |
|---|---|---|
| 祝婶 | zhu-shen | 灰发髻、珊瑚衣、围裙、汤勺 |
| 阿缄 | a-jian | 邮差帽、蓝衣、邮袋、封蜡信封 |
| 温砚 | wen-yan | 工匠围裙、木柄锤、工具箱 |
| 陆见微 | lu-jianwei | 眼镜、紫色长外套、展开的记录册 |
| 拾一 | shi-yi | 青绿机偶、双目面罩、救援背包 |
| 关卡向导 | stage-guide | 白发白须、青绿长袍、地图与引路旗杖 |
| 城镇商人 | merchant | 青绿帽、斜挎包、托金币 |

- `masters/`：48×64 RGBA透明背景原图，每张不超过12色。
- `display/`：384×512，最近邻8倍放大，保持透明背景。
- `npc-cast-overview.png`：带姓名图集，展示用途。
- `npc-atlas.png` / `npc-atlas.json`：336×64透明横排图集，逐帧坐标与脚底锚点。
- `manifest.json`：人物身份、路径、原生尺寸、逐图颜色与像素检查数据。
- `review/`：轮廓检查和逐轮检查记录。
- `build.py`：六位新角色完整绘制源，商人使用`sources/merchant.png`已确认源图；`sources/merchant-build.py`保存商人的原绘制源。

运行：使用已安装的pixel-art-studio技能及Codex内置Python执行`build.py`。所有新图由Sprite像素绘图接口在原生分辨率绘制，无图像模型调用。光源为左上，深紫描边，无抖色、无半透明边缘。

本轮交付静态待机人物图片，尚未制作行走/攻击动画或接入游戏，不改变现有剧情或存档。普通人类图是造型设定图，不表示石化角色已在游戏中复苏。
