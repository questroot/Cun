# 福地像素美术工作源

用户先要求地图、建筑、宝箱、草药和植物按每轮3张生成、逐张检查，随后明确要求**调用图像网关生成精细图片**。当前以网关版本为交付目标；本地代码绘制版本保留作早期草稿。

## 当前网关流程

- `plan_gateway.py` 只整理54张提示词与18轮队列，不调用API。
- 使用已安装 `imagegen` 技能的 `scripts/image_gen.py` 直接调用本机配置的网关，模型 `gpt-image-2`、高质量、并发1。密钥和网关配置不写进工程文件。
- 每张返回后先检查原图；`review_gateway.py --prepare` 离线生成预览或透明抠图，再逐张查看，明确记录接受或返修。未生成、未检查的项目保持待办状态。
- 续作按一张生成、一张检查、一张压缩串行推进。`--prepare` 同时保存 `compressed/` 无损WebP，与候选图逐像素校验一致后记录大小；原始PNG保留。压缩通过不等于视觉检查通过。
- 每轮最多4张（2026-10-21用户调整），不发起并行生成。限流、超时或网关错误先记录，再按返回的等待时间退避；不反复密集重试，不用较差模型悄悄代替。
- 原始图、提示词、队列与检查预览在仓库根 `output/imagegen/fudi-fine/`。最终实际进度见该目录 `queue.json`；草稿和提示词不等于完成图片。

54张包含：10张地图场景、10座独立建筑、6种宝箱外观、11种草药图标、10套三阶段植物、7种环境植物。地图场景是美术底稿，模型生成的墙体和道路不保证与既有碰撞精确重合，须核对后再进入可行走地图。

续作检查支持队列条目显式设置 `chroma_key: "green"`；默认仍是品红。网关若返回原生透明图则保留alpha，跳过色键移除。无损WebP使用 `exact=True`，连透明像素的RGB也逐像素校验。第11–13张已检查为美术候选，细小色边、建筑风格和运行时缩放仍需接入前确认；实际尺寸以队列 `actual_size` 为准。

```powershell
# 使用 Codex 自带 Python；需已安装 imagegen 和 pixel-art-studio 技能。
python pixel-art/fudi-world/plan_gateway.py
```

`review_gateway.py 1 --prepare` 准备第一张的离线检查；查看图片后才使用 `--accept --notes '实际观察到的结论'` 或 `--reject --notes '具体返修原因'`。透明对象使用平坦品红底，离线去除品红，保留原始图；抠图还须检查暗底和亮底边缘。

## 早期本地草稿

`build.py` 使用 `pixel-art-studio` 的 `pixelstudio.py` 和 Pillow，直接绘制像素，无网络调用。`drafts/`、`previews/`、`silhouettes/` 和游戏目录中 `assets/pixel/fudi/` 的现有导出属于该阶段，不能计为精细网关版本完成。运行源可复现，但当前不继续该生产流程，也未将这些草稿替换进实际游戏。
