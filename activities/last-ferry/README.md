持续冒险中的一个地方故事：进入人与怪异交织的渡口生活，理解问题并选择介入方式，而不是见到怪异就消灭。

## 独立运行入口

双击 [Play.cmd](Play.cmd)。脚本使用本仓库已准备的内置 Godot，先导入再启动此独立活动；不改变公共启动器和既有原型。首次尚未准备引擎时，先使用根启动器准备内置引擎，或指定已有引擎：

```powershell
.\activities\last-ferry\Play.ps1 -EnginePath '你的Godot路径'
```

仅该命令启动本活动；根公共启动器目前仍启动旧原型，不宣称已整合活动列表。脚本不联网下载引擎。`Play.cmd` 的执行策略参数仅用于本次子进程，不修改系统全局策略。

## 操作

WASD / 方向键走动，靠近圆环物件或人物按 E 交互；也可用鼠标点右侧交互与场地下方方向按钮。J 打开记录，I 查看物品，Esc 暂停。入夜与危险动作均先确认。水声默认关闭，可自行开启；它是本地合成底音，不是录音素材。

进度需手动保存。活动使用独立用户目录 `Cun-LastFerry-v1`，不会改原型存档。详细解法放在二次确认的剧透帮助里，建议第一次先自己探索。

## 复跑验证

运行 [Verify.ps1](Verify.ps1) 执行导入与实际规则/主场景测试；加 `-Window` 再执行真实窗口自动流程。使用被忽略的测试目录，不写生产存档。它不是替代真人试玩的验收按钮。

## 首版验证标准

- 返乡者和学徒各能独立走到留灯结局；学徒通过明确的信息交换，而不是自动获知船上信息，走到解缆结局。
- 玩家可以从场景、物品和交谈看出白灯/黄灯/钟舌的关系，记录本不是作者直接公布谜底。
- 两次危险行动分别警告、允许取消；普通探索不增加污染；漫水也能结束并离开。
- 恢复旧约、告别和漫水有不同可见尾声；尾声不是只有结算文字。
- 独立存档保存身份、阶段、物品、证据和结果，坏档有明确错误且不自动覆盖；不改旧原型存档。
- 暂不实现传统战斗、小模型NPC、收灯、第二地区和时间胶囊。结束页明确首版边界。
