# Cun

一个与伙伴共同打造游戏的工作空间。**正式游戏方向尚未确定，当前先搭建协作舞台，不提前锁定玩法、引擎或大型框架。**

已有 `card-demo` 是“灵伴回合冒险 MVP”Godot 原型，保留原样作为实验材料；它不自动代表项目最终方向。

## 启动当前原型

Windows 下载完整仓库后，双击 **[Launch.cmd](Launch.cmd)**。启动器会检测或让你选择已有Godot，并提供游戏/编辑器、文档、日志入口。无需Python即可打开启动器；仓库内置 [Godot 4.7.2压缩包](.setup/Godot/README.md)，首次可校验解压，无需联网下载。未打包独立游戏exe。详见 [启动器说明](launcher/README.md)。

启动器、内置Godot和文档均在默认主分支 `main`。首次获取：

```powershell
git clone https://github.com/questroot/Cun.git
cd Cun
.\Launch.cmd
```

已有仓库：先保留本地修改，再 `git switch main` 和 `git pull --ff-only`。无需切到历史功能分支。

本地原型新增 **GM 工具**：主城右下角点击进入，也可在宠物背包中选中宠物后点击“GM 升级”。输入目标等级（1–999），提升选中宠物或全部已拥有宠物；只升不降，保留经验。选择关卡后点击跳转，会解锁至该关并进入编队，确认阵容后开战。操作立即保存到当前存档，Esc 可关闭面板。

**双游戏与地图**：启动器下拉框可选择“游戏选择大厅 / 灵伴回合冒险 / 福地”。默认游戏入口是选择大厅；主城、外缘、水域和福地都有“地图 M”入口。福地在“菜单 Esc”中切换游戏，其他场景保留原按钮。点击地图区域可看物品种类与稀缺程度；福地显示本轮剩余 / 初始份数，采集后实时减少；浮台按实际打捞、生产与加工规则展示。

**福地十域探索**：保留青岚灶街、旧城邮驿、赤岩钟楼、灵泉记录站、归航救援营，新增雨灯湿地、断桥驿路、松烟炭林、镜沙档案馆、霜脊瞭望岭，延续祝婶、阿缄、温砚、陆见微和拾一的剧情线索。各图3600×2400至5200×3400，带跟随镜头、碰撞地形、小地图、30处人物线索和30个方向出口。WASD移动，J/K/L攻击，E调查/休息/通行，B行囊与见闻，M跨区旅行；靠近资源自动采集。十地60名初始守卫和六只首领肃清后仍可自由探索。区域间保留当局采集、战斗、调查与最后位置，离开游戏/重开后重置，不写入灵伴存档。详见[十域地图说明](docs/fudi-maps.md)。

**福地九图美术替换**：灶街至档案馆已使用生成好的九张1536×1024地图，场景和小地图同步；按画面道路、桥面、建筑前庭校准通行、调查、入口与首领落点。原PNG保留，运行使用逐像素验证的无损WebP。霜脊瞭望岭暂保留原场景；十地同心圆布局与六首领分区保持。见[素材与导航说明](card-demo/assets/backgrounds/fudi/README.md)。

**福地细绘宝箱与药材**：普通/异变宝箱的关闭、守卫、净化与领取状态，11种野外草药图标，以及10种药圃三阶段生长图已替换原代码造型。透明运行图从用户提供的生成源抠像、去水印和缩放得到，原始图不改；交互距离、掉率与生长规则保持。见[素材与复现说明](card-demo/assets/fudi/fine/README.md)。

**福地简洁界面与远视角**：常驻界面改为紧凑地图名/生命顶栏、地图M/行囊B/装备C/菜单Esc四入口、小地图及底部技能/交互提示。声音、GM与切换游戏收进菜单，详细规则保留在M/B；建筑效果、危险和附近首领按需提示。世界缩放为80%，地图窗口增高至560像素，同屏可见1560×700世界范围，界面字号及按钮保持原尺寸；菜单打开暂停探索。

**福地人物交流与购买**：靠近已绘制的十位NPC按E，显示对应人物和交流/商品面板；商人可切换“交流与委托”“购买商品”。使用现有灵晶结算，买入物品进入行囊，装备可按C穿戴；各商人库存独立，跨图保留、重开重置。长祷者随巡游兜售高阶异变装备、凝灵石与记忆晶砂。E/Esc关闭，交流交易时暂停探索。详见[交流与商品规则](docs/fudi-npc-exchange.md)。

**福地天气与生态**：十张大地图各有气候轮换，每75秒变化，含润雨、晴光、灵雾、疾风、炎阳、雷雨和霜雪。每地六处再生药圃，在适生天气累计18–28秒成熟，靠近采集后可重新生长；小地图绿点指示药圃，M 看天气/植物/怪物，B 查看生态记录。天气改变石灵的生命、移速、伤害及材料掉落，保留受伤比例，不复活已清除守卫。跨图保留当局生态，地图/对话/行囊/结算时暂停；重开重置，不改灵伴存档。规则见 [天气系统](docs/weather-system.md)，隔离检查：`powershell -NoProfile -ExecutionPolicy Bypass -File tests/weather.tests.ps1 -Render`。

**福地随机陷阱（暂时停用）**：按用户要求关闭地图陷阱触发、伤害与附加效果，代码和配置保留，M/B显示停用；首领技能不受影响。以下为恢复启用后的规则：十张地图各有两类环境危险，从蔓刺、孢子、朽板、悬牌、落石、地裂、电涌、水压、薄冰、风卷物十种陷阱中按地形搭配。只在视野内随机预警，黄圈出现后有1.3–1.7秒可用WASD走开；命中造成伤害及短暂减速或击退，相关天气提高权重并增强伤害。出生点、人物地标和出口安全；地图/对话/行囊/结算时暂停，切图取消当前危险。M查分布、B查记录；[规则与专项检查](docs/map-traps.md)。

**福地圆环地图与首领分布**：M总览采用大圆套小圆，原五地在内环、新五地在外环，五条辐射通道连接对应区域；圆环与线条对应实际出口。六只首领分驻六地：内环灶街荆冠鹿骑、钟楼锈钟守望者、救援营沉潜重装；外环驿路残旗剑士、档案馆霜典记录者、瞭望岭灰翼审判者。总览暖色边框及菱形标出首领驻地，小地图红菱形指路，M/B查看坐标和掉落；JKL可战斗，红圈预警后走出闪避。血量与死亡跨图保留，全部守卫和首领击败后可继续探索。详见 [首领规则与验证](docs/fudi-bosses.md)。

**福地装备掉落**：按现有物品与武器图接入20件装备；小怪35%随机掉一件，Boss必掉一件，并保留首领材料奖励。按地图和首领配置物品池，地面显示原图，靠近自动拾取，B查看图片及数量、M查看掉率。规则与隔离检查见 [装备掉落说明](docs/fudi-loot.md)。

**福地宝箱**：每地图2个普通箱，随机额外生成异变箱；小地图金/紫方块指路，靠近按E。异变箱触发4小怪和弱化Boss，清空后再E领奖；守箱Boss60%概率掉异变品质装备，原非零属性提高30%向上取整，可在C面板穿戴并实际生效。原常驻Boss仍必掉装备。详见 [宝箱规则与验证](docs/fudi-chests.md)。

**福地人物装备**：点击“装备 C”或按C，穿戴已拾取的20件现有装备。支持武器、上衣、护腿、战靴、项链、戒指六个栏位，可筛选、对比、替换、卸下；伤害、减伤与移速立即影响实际战斗。面板打开时暂停探索，C/Esc关闭。穿戴跨地图保留，本轮重开或离开后清空。详见[装备说明](docs/fudi-equipment.md)，隔离验证：`powershell -NoProfile -ExecutionPolicy Bypass -File tests/equipment.tests.ps1 -Render`。

**套装与武器特效**：三套装备按2/4/5件激活，追归提供移速、冷却与命中恢复，烽炉提供增伤、灼烧和强化震荡，镜潮提供减伤与周期护盾。五把武器各有回响、低血量增伤、三向灵弹、缚根减速或范围余震；附实际战斗浮字、特效提示与护盾护环。C面板顶部“套装与特效”查看条件和激活状态，单件详情查看武器效果；详见[完整规则](docs/fudi-equipment.md#套装与武器效果)。

**装备融合**：C →“装备融合”，消耗1件同部位备用装备，或使用玄铁、旧铁片、细铜丝提升目标属性。显示消耗与提升预览，最高+10；每次只强化1件，穿戴中目标立即生效，保留品质、套装及武器特效，跨图保留、重开清空。详见[融合规则](docs/fudi-equipment.md#装备融合)。

双游戏、地图、动作输入、GM、行走与原玩法的隔离回归：`powershell -NoProfile -ExecutionPolicy Bypass -File tests/exploration.tests.ps1 -Render`。`-Render` 使用真实窗口并保存截图；全程使用工程副本和独立测试存档。

**福地大型建筑**：十张地图各有一座主题建筑，每轮随机附带增益或减益。走入门口光圈获得60秒效果，绿光增益、紫光减益，含移速、伤害、减伤、治疗和冷却变化；增益与减益各保留一种，同类替换，跨图保留。M/B查看建筑效果与入口坐标，左上仅在效果生效时显示状态。详见[建筑规则与验证](docs/fudi-buildings.md)。

GM 与现有玩法回归可运行 `powershell -NoProfile -ExecutionPolicy Bypass -File tests/gm.tests.ps1 -Render`；自动复制工程并使用独立测试存档，`-Render` 同时检查真实窗口渲染并截图。

**福地声音**：hybrid-v3十地与六Boss各用不同乐器独奏开场，再展开8–12种采样乐器的交响编配；地图保留烟火圆舞、书信室内乐、水纹与雪山等特色。六Boss重写独立旋律、调式与鼓点，加入钢琴、木/电吉他、电贝斯和六类摇滚。每首六段结构、约1分49秒至3分33秒，交战/脱战淡化、天气底声与原22段音效保留。“菜单 Esc → 声音”调整三类音量或静音。[整套试听与MIDI](assets/audio/orchestra-listening.html) / [来源与复现](docs/fudi-audio.md)，人工听感待验收。

## AI 游玩 MCP

[公共游玩MCP说明](tools/play_mcp/README.md)提供标准 stdio MCP：入口 `python tools/play_mcp/server.py`，工具包含项目列表、隔离启动、观察、真实输入和停止。公共原型先接入，个人活动复用同一协议；默认独立存档、仅本机回环桥，未开启时不监听。不提供GM、任意代码或内部状态写入，不修改用户DSH配置。另有供现有Agent调用的本地HTTP便利代理，它不是标准MCP HTTP传输。实际验证和未验项以共享状态为准。

## 每次工作先看这里

**[PROJECT_STATUS.md](PROJECT_STATUS.md)** 是共享现状入口：已做什么、实际验证、未验证、风险和下一步。成员/Agent先读它，工作结束核对并按事实更新；规则在 [AGENTS.md](AGENTS.md)，分工在 [文档维护规划](docs/documentation-plan.md)。

启动器打开/刷新会自动生成本机 `.local/project-snapshot.md`，不提交Git，也不是后台持续监控。正式新游戏方向仍未锁定。

## 第一次来，先做这三件事

1. 把 [完整Agent讨论材料](docs/design/agent-discussion-kit.md) 发给自己的Agent，按内置提示词梳理个人思路、自己看总结；无需统一填票或发回。
2. 新点子自愿分享后写进 [奇思妙想池](docs/design/ideas.md)；[问题总表](docs/design/questions.md)、[简短选择表](docs/design/ballot-round-1.md) 和 [脑图](docs/design/discussion-map.md) 是辅助，不是必交作业。
3. 再按需看 [参与指南](CONTRIBUTING.md)、[文档导航](docs/README.md) 和 [资源管理入口](assets/README.md)。当前先整理思路和问题，不急着认领新增玩法制作任务。

可直接转发给伙伴：[PNG脑图](share/cun-discussion-map.png) / [离线讨论与选择页](share/team-discussion.html)。离线页没有提交按钮，不会保存或上传回答，选择后请打印为PDF或按回复格式发回。

## 资源管理器：现在就能用

Python 3.10+，只用标准库，无需安装依赖。在仓库根目录运行：

```sh
python tools/assets.py check
python tools/assets.py catalog
```

然后双击打开 [资源图册](assets/catalog.html)（先生成，此文件不入 Git）。可以搜索、按分类/状态过滤、预览图片、打开文件。登记维护通过 [资源工具](tools/assets.py) 完成，操作示例见 [资源指南](assets/README.md)。

[资源清单](assets/registry.json) 包含38项声音（16首采样乐团原创配乐、22段程序合成环境/操作音效）；均为 `draft`，配乐附音源来源和许可原文，素材整体许可仍待确认。**不推断已有素材的作者、许可或商用权限**。扫描新资源不会覆盖已登记的来源、标签或许可。

```sh
python tools/assets.py scan card-demo/assets
python tools/assets.py check --release
python -m unittest discover -s tests -v
```

普通检查允许未知许可但显示警告；发布检查会拦截未知来源和未批准条目，因此现有导入清单不会通过发布检查。这是工具门禁，不是法律授权证明。

## 目录约定

```text
Launch.cmd   Windows可双击入口
launcher/    WPF启动器、核心函数和说明
AGENTS.md    成员/Agent工作入口规则
PROJECT_STATUS.md 共享现状，每轮核对维护
card-demo/   现有独立原型，不在本次底座搭建中改动
assets/      跨原型的资源登记信息和本机生成图册，不复制素材
docs/        架构、团队约定、路线图与四个短模板
tools/       资源/文档检查工具；讨论PNG导出另需Pillow
share/       自包含的讨论页和转发脑图
tests/       工具回归测试（不是游戏实机验收）
.github/     Issue、PR 模板与基础 CI
```

正式工程目录在方向与引擎确定后再建。现在不创建空游戏框架、联网、ECS、插件系统或全局事件总线。

## 想跑已有原型

可以通过 [Windows启动器](Launch.cmd)，或用兼容的 Godot 编辑器导入 [原型配置](card-demo/project.godot)。配置声明 `4.7`、`GL Compatibility`，默认入口是 `MainMenu.tscn`，可进入原有灵伴或新增福地动作试玩。**配置声明不是运行验证**；当前检查结果及历史问题见 [共享现状](PROJECT_STATUS.md)。

## 接下来建议做什么

当前各自把完整材料交给自己的Agent，先整理问题、候选与个人偏好，自己看总结；无需集中填票或回收。个人愿意分享时再交流，个人结论和Agent建议都不是团队定案。后续明确选择路线再谈实验与制作，不因已有素材和模块被迫选某种游戏。

项目代码许可、素材权利、成员署名/作品归属与发布方式仍待团队确认。仓库公开不等于已授予开源、商用或再分发许可，当前不擅自添加 LICENSE。
