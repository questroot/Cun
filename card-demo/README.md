# Cun 既有 Godot 工程

这个工程目前承载多个作品。它们的入口和玩法相互独立，但暂不移动共享工程、资源或存档。

- [灵伴回合冒险](games/spirit/README.md)：编队、关卡与回合战斗。
- [福地](games/fudi/README.md)：十域动作探索。
- [海底水世界](games/water/README.md)：浮台经营与下潜。此入口在公开 `main` 中已接入，早于接入的分支可能没有启动选项。

开发时用 Godot 4.7.2 打开[工程配置](project.godot)。共享素材、管理器和旧场景继续留在原路径，避免破坏场景引用、编辑器 UID、自动检查及老存档。新增某一作品专用的文档，可归入该作品的目录；运行资源和代码迁移需由相关负责人先核实共享引用。
