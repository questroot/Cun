# 福地声音资源

38项声音：新版10首地图交响曲、6首首领战斗交响曲（OGG），原5段环境声与17段操作/事件音效（WAV）。

当前hybrid-v3为原创谱面，通过GeneralUser GS 2.0.3采样虚拟乐团渲染。16首各用不同乐器独奏四小节，随后展开8–12种乐器、六段曲式，64/72小节，约1分49秒至3分33秒。六Boss独立重写旋律/调式/鼓点，分别使用失真吉他、小提琴、电贝斯、钢琴、清音电吉他与钟琴开场，融合六类摇滚和管弦乐；非现场录音。22音效仍为原v1程序合成，内容不变。

谱面与渲染器：[`fudi_orchestra_scores.py`](../../../../tools/fudi_orchestra_scores.py)、[`build_fudi_orchestra.py`](../../../../tools/build_fudi_orchestra.py)。[整套试听页](../../../../assets/audio/orchestra-listening.html)可试听/下载MIDI；`manifest.json`含段落、声部与校验值。音源[许可原文](../../../../assets/audio/GENERALUSER-LICENSE.txt)及来源已保留，详见[配乐说明](../../../../docs/fudi-audio.md)。游戏“菜单 Esc → 声音”调整音量，原切曲/暂停保留；人工听感待验收。
