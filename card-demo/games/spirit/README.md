# 灵伴回合冒险

从主城出发，给主角和灵伴编队，在九宫格上打一场手动回合战斗。当前是可试玩的 Godot 原型。

## 怎么玩

1. Windows 双击仓库根 [Launch.cmd](../../../Launch.cmd)，选择「灵伴回合冒险」；也可以从旧的游戏选择大厅进入。
2. 从主城与向导或关卡入口开始，选择灵伴、安排站位，再确认开战。
3. 战斗里选择技能和目标；胜利后积累经验，继续挑战后续关卡。

已有灵伴进度沿用原存档。主城与背包里的 GM 工具是开发功能，升等级或跳关会写当前存档；普通试玩不需要点它。
