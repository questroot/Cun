# Cun 团队文档

Cun 由用户与伙伴共同开发。正式游戏方向尚未确定；当前先搭建便于合作、试错和实机验证的舞台，不先确定完整架构。

## 每次工作必读与启动入口

- **[共享项目状态](../PROJECT_STATUS.md)**：先核当前阶段、实际实现、已验证/未验证和允许范围；每轮结束核对更新。
- [Agent工作入口](../AGENTS.md)：阅读、修改、文档维护和权限约定。
- [Windows启动器](../Launch.cmd) / [使用说明](../launcher/README.md)：当前原型的本机游戏/编辑器入口，不是独立打包游戏。
- [文档维护规划](documentation-plan.md)：共享状态、候选、决策、源码与本机快照各负其责。
- [福地十域地图](fudi-maps.md)：十张大地图的内外同心圆布局、30处人物线索、连通出口、旅行与输入说明。
- [福地人物交流与购买](fudi-npc-exchange.md)：十位人物交流、按职责商品货架、灵晶结算、长祷者高阶稀有装备与独立库存。
- [福地NPC与任务标记](fudi-npcs.md)：九位固定人物、十图巡游长祷者、红黄蓝像素感叹号/问号与调查委托。
- [福地GM工具](fudi-gm.md)：F8打开，1–10倍角色移速、十图出生点传送、指定人物或全部调查线完成；本轮有效，附隔离验证。
- [福地大型建筑](fudi-buildings.md)：十地主题建筑、随机增益/减益、入口光圈、60秒状态与隔离验证。
- [福地地图首领](fudi-bosses.md)：H01–H06分驻六地、内外环各三只，含技能预警、掉落和隔离验证。
- [攻击与天气像素特效](combat-weather-effects.md)：38组动画、六首领各四招、守箱变体、七属性小怪与七种天气，含躲避规则及隔离验证。
- [福地地图音频](fudi-audio.md)：16种独奏开场、六Boss独立旋律与交响/摇滚、钢琴/吉他/电贝斯、8–12种采样乐器、分轨MIDI及[整套试听](../assets/audio/orchestra-listening.html)，含音效、切换设置与来源。
- [福地装备掉落](fudi-loot.md)：20张现有装备/武器图，小怪35%随机掉落、Boss必掉一件，附拾取与行囊规则。
- [福地宝箱与异变守卫](fudi-chests.md)：随机宝箱、怪物群与弱化守箱Boss、概率强化装备掉落和实际属性提升。
- [福地天气与生态](weather-system.md)：十地气候轮换、适生药圃、天气怪物与材料掉落，附隔离验证入口。
- [福地地图随机陷阱](map-traps.md)：十地搭配十种环境危险、预警闪避、天气增强与暂停/转图规则。

- [福地人物装备](fudi-equipment.md)：C打开六栏装备面板；穿戴、替换、卸下、属性对比，三套2/4/5件效果、五把武器特效，以及消耗同类装备/金属的+10融合，附预览和隔离验证。

## AI 游玩公共能力

- [公共游玩MCP](../tools/play_mcp/README.md)：标准stdio协议、项目接入与现有Agent调用说明；验证进度见共享状态。仅玩家可见信息和真实输入，不提供GM或任意状态写入；原型与个人活动复用同一接口。注册配置不会自动写入各成员的宿主配置。

## 新游戏方向：整理想法与问题，先不急着制作

- **[交给自己Agent的完整讨论材料](design/agent-discussion-kit.md)**：自包含背景、40题候选/取舍/建议、讨论提示词与个人摘要格式；每人自己讨论、自己查看，不要求统一交票。
- [讨论导图与群发说明](design/discussion-map.md)：辅助查看主干，不是要求集中回收的流程。
- [奇思妙想池](design/ideas.md)：团队持续记录新点子的入口，收录不等于采纳。
- [40题问题总表](design/questions.md)：方向、设计、实施三轮处理，全部尚未定案。
- [8题简短选择表](design/ballot-round-1.md)：可选辅助，保留其他、不确定与反对意见，不要求提交。
- [离线讨论页](../share/team-discussion.html)：自包含脑图、选择票和问题总览；不收集或保存回答。

## 个人独立活动

- **[末班渡船](../activities/last-ferry/README.md)**：本用户已授权先补齐故事，再制作独立首版；[故事与流程](../activities/last-ferry/STORY.md)、[场景对白](../activities/last-ferry/DIALOGUE.md)。它不采用石化设定，不代表其他伙伴或团队的统一世界观；实现/验证进度以共享状态为准。

## 历史候选规划：尚未批准实施

- [石化世界与异灵远征规划](design/project-plan.md)：整理用户和伙伴讨论、世界观、操作方案、卡牌/融合、美术与现有骨架接入；明确建议与未决项。
- [首个可玩版本计划](design/first-playable.md)：最小范围、分段交付、远征/存档数据边界和真实试玩判据。

这是一版候选规划，不代表团队已选定操作、美术或正式引擎，也不意味着新玩法已实现。

## 按需填写，不要求全部建立

## 现有原型与事实边界

[card-demo 项目配置](../card-demo/project.godot)显示：项目名为“灵伴回合冒险 MVP”，`config/features` 标记为 `4.7` 与 `GL Compatibility`，默认入口是 `MainMenu.tscn` 游戏选择大厅，提供灵伴与福地动作试玩，已有数据、游戏、UI、战斗四个 Autoload。地图与操作见[根使用说明](../README.md)。配置标记不等于已验证本机安装或可正常运行。

该项目是保留的 Godot 原型，不迁移，不认定为正式游戏方向；未来正式工程的位置与引擎另行确认。本文档未报告任何实机验证结果。
