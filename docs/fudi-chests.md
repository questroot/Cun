# 福地普通宝箱与异变宝箱

十张福地地图各生成2个普通宝箱，并各以35%概率额外生成1个异变宝箱；如果整轮随机结果没有异变箱，会随机选一张地图补1个。箱子远离出生、人物线索和出口，位于可通行地面，箱间至少240像素。每轮重新随机，跨地图保留。

小地图的金色方块为普通箱，紫色方块为异变箱。靠近105像素内按 **E** 操作，底部显示当前交互提示；**M** 查看所选地图剩余宝箱，**B** 查看全部区域状态和规则。

| 类型 | 开启与领奖 | 箱内奖励 |
| --- | --- | --- |
| 普通宝箱 | E直接开启，地面出现奖励，靠近自动拾取 | 1件本地区普通装备＋3份本地区材料 |
| 异变宝箱 | 首次E触发守卫战；清空守卫后，再按E领取 | 1件本地区普通装备＋3份本地区材料，另有守卫掉落 |

异变箱唤出4只小怪和1只守箱首领，开场留1.2秒安全预警，生成点距玩家至少125像素、与箱子之间地面可通行。守卫独立于天气怪物与地图常驻首领，天气不会覆盖其数值。

- 守箱小怪：生命36、伤害6、移速72；击败时按原小怪35%规则随机掉一件地区普通装备，只结算一次。
- 守箱首领：复用地区对应H01–H06美术，生命和逐招伤害为该原型首领的60%（向上取整），移速55；2026-10-21起继承对应首领的四种技能与8帧特效，按顺序轮换，位置/朝向在预警时锁定，沿用各招1.05–1.9秒预警及对应圆形、直线、扇形、十字、环形、三点闪避规则，详见[攻击特效](combat-weather-effects.md)。和其他伤害共享受伤保护，装备减伤、护盾、武器减速及攻击效果正常生效。
- 守箱首领有60%概率掉1件本地图物品池的**异变装备**，40%不掉装备；不领取地图常驻首领的固定材料或必掉奖励。原六只常驻首领继续必掉装备。

## 异变装备属性

20种现有装备各有对应异变品质，沿用原图，名称增加“异变·”，地面光圈为紫色，单独计数与穿戴。原有每项非零伤害、减伤、移速乘1.3后向上取整，零值仍为零，不修改已存在的普通副本。例如灰烬回响伤害12→16、减伤2→3；烽炉胸甲伤害1→2、减伤3→4。

强化装备可从B行囊查看，在C人物装备中比较、穿戴、替换、卸下，提升进入实际战斗与移动；原套装归属和武器特效保持生效。没有额外提升套装阈值奖励或武器追加伤害，也不包含手动强化或永久成长。

## 生命周期

未击败全部守卫时不能领取异变箱奖励；先击败首领但小怪存活时仍锁定。重复按E、重复清理尸体和重复靠近奖励都不会重复发放。已触发的守卫战会计入清场条件，未开启宝箱不阻碍正常通关；胜后继续探索可开箱、清守卫与领奖。

地图、装备、对话、行囊和结算暂停守卫；离开区域冻结当地战斗，保留血量及掉落，旅行取消首领旧预警并留出准备时间。重开或离开福地清空箱子、战斗和本轮奖励，不写灵伴存档。
