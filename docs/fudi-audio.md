# 福地地图音效与交响配乐

2026-10-21按用户“不要同一种乐器开头、每只Boss调子不能重复、加入钢琴/吉他/贝斯/摇滚”的反馈升级到hybrid-v3。16首各用不同的真实采样乐器独奏四小节，取消共同低弦/竖琴铺底及尾奏叠入开头；随后分层加入乐团。六首Boss重新写作A/B旋律、和声与鼓点，并加入钢琴、木吉他、清音/过载/失真电吉他、电贝斯及标准鼓组。旋律与编配由项目内谱面定义，使用GeneralUser GS 2.0.3采样音源渲染虚拟乐团；非现场录音。原22段天气/环境/操作音效保持逐字节不变。

可双击打开[整套试听页](../assets/audio/orchestra-listening.html)，逐首播放，也可下载分轨MIDI进一步编曲。合成器与音源只在制作时使用，游戏直接播放成品OGG。

## 游戏播放与操作

- 音乐为44100 Hz立体声Vorbis OGG；环境与短音效仍为22050 Hz/16-bit WAV。尾声终止式短渐隐接回独奏，保留接缝平滑，不将收尾合奏尾音回绕叠入开场。
- 两播放器1.2秒等功率交叉淡化。接近存活首领520像素且距其家点650像素内切战斗曲，脱战2.5秒滞后；死亡/旅行解除。异变宝箱首领按实际art身份选曲。快速连续旅行结束当前淡化后使用最新请求。
- 四种脚步、JKL、命中、受伤、采集、首领/陷阱预警、首领倒下、宝箱、调查、胜败、远雷及地域/天气底声保留。
- “菜单 Esc → 声音”分别调整音乐/音效/环境，支持全部静音。设置仅当前场景有效。地图、对话、行囊、装备和声音面板暂停探索并压低音乐；结算淡出，继续探索恢复地图曲。离开福地释放全部播放器，不修改全局总线或灵伴存档。
