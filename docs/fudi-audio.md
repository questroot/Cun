# 福地地图音效与配乐

本轮为十张福地地图制作16首循环曲、5段循环环境声及17段操作/事件音效。由 `tools/build_fudi_audio.py` 内的固定旋律、和声与振荡器/噪声合成生成，无外部录音、歌曲或音色采样；不是第三方音乐生成服务产物。当前是可替换的合成配乐原型，音乐审美、听感与最终音量仍待人工试听。

## 操作与设置

- 四种脚步（草地、石地、浅水、雪地），按实际移动距离触发，碰墙/停步不播放；切图不算步行。
- J挥斩、K施法、L震荡、命中、受伤、采集、首领/陷阱预警、首领倒下、宝箱、调查、胜利、失败和雷声。
- 润雨/雷雨叠加雨声，疾风/霜雪叠加风声；雷雨间隔约14秒远雷。天气变化渐隐/渐入环境层。
- 右上“声音”调整音乐、音效、环境三个独立音量，或全部静音；Esc收起。设置只在当前福地场景有效，重开恢复默认。
- 设置面板暂停探索，地图/对话/行囊/装备界面压低音乐与环境声并取消短音效；结算淡出音乐与环境层，保留结算短曲；继续探索恢复地图音乐。
- 12个短音效声部，同类音效限频；声部满时丢弃新事件。所有播放器随福地释放，不修改Master总线、灵伴存档或其他游戏的音量。

## 文件与复现

- `card-demo/assets/audio/music/`：`map_<区域>.wav` 与 `boss_H01` 至 `boss_H06.wav`。
- `card-demo/assets/audio/ambience/`、`sfx/`：环境与事件声音。
- `card-demo/assets/audio/manifest.json`：标题、时长、节拍、峰值/RMS、SHA256及生成来源。
- `card-demo/scripts/scenes/fudi_audio.gd`：场景独立播放、交战判定、淡化与设置；福地只增加声音信号及设置暂停判断。
- 重建：安装NumPy的Python运行 `python tools/build_fudi_audio.py`。不联网、不改变其他素材；改音频后重新核对清单指纹。
- 隔离检查：`powershell -NoProfile -ExecutionPolicy Bypass -File tests/audio.tests.ps1 -Render`，工程副本/独立存档，真实音频混音采样与窗口截图均落本机。机器检查不代替人工试听。

这些新增音频来源可追溯为本项目内程序合成；仓库整体许可与最终发布仍按项目现有规则处理，未替团队另行授予发行许可。
