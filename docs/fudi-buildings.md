# 福地大型建筑与随机效果

十张地图各有一座与地形主题对应的大型建筑。建筑使用 Godot 绘制屋顶、柱廊、台阶、塔楼、烟囱或观星仪等轮廓，是可游玩的代码美术原型。复用原有第三块障碍的占地，不新增道路碰撞；入口位于建筑南侧，保持出生点、人物、资源和出口连通。

## 地图与随机池

每轮开始，各建筑从当地四种效果中等概率抽取一种，两种增益、两种减益，因此增益和减益各占50%。旅行、天气变化、再次触发都不重抽，重开才重新随机。

## 触发与查看

走进建筑门口半径100的光圈自动触发，无需按E。绿光代表增益、紫光代表减益，建筑前显示名称和具体效果；小地图用对应颜色的空心方框标记入口。M地图区域详情和B行囊见闻显示建筑、效果、入口世界坐标与本轮触发次数，右下方显示当前效果及剩余秒数。

每次持续60秒有效游戏时间，离开光圈或跨地图仍保留。站在圈内不会持续刷新；走出后再次进入可刷新。最多同时保留一种增益和一种减益，同类效果替换，不叠层；两类作用于相同属性时相乘，例如顺风与滞重同时存在时移速为原值的1.2×0.8＝0.96倍。

| 类型 | 效果 | 实际作用 |
| --- | --- | --- |
| 增益 | 顺风 | 移速×1.2 |
| 增益 | 振奋 | J/K/L直接伤害×1.25 |
| 增益 | 庇佑 | 受击原始伤害×0.75 |
| 增益 | 复苏 | 每秒恢复2生命，上限100 |
| 减益 | 滞重 | 移速×0.8 |
| 减益 | 衰弱 | J/K/L直接伤害×0.8 |
| 减益 | 易伤 | 受击原始伤害×1.25 |
| 减益 | 灵滞 | 新释放技能的冷却×1.25 |

移速、直接伤害和新冷却先计算装备效果，再乘建筑系数；伤害向上取整。受击先乘建筑系数并向上取整，再走装备减伤、套装减伤和护盾流程，保留既有受伤保护。武器灼烧、回响、余震等追加伤害沿用各自规则；建筑直接伤害系数不再额外乘到这些追加结算。灵滞不会修改已经开始的冷却。治疗按实际经过时间累计小数，结算失败后不能复活。

地图、对话、行囊、装备页、切换确认及胜负结算暂停建筑计时、治疗和入口触发。跨图保留已抽取的建筑效果和当前状态，重开或离开福地清空；不写入原有灵伴存档。建筑目前不可进入内部，也没有建筑升级或持久化规则。
