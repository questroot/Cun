# 福地人物装备

进入福地后点击右上角“人物装备 C”，或按 **C**。选择已拾取的装备，点击“穿戴装备”；同部位已有装备时点击“替换穿戴”。左侧六个栏位可筛选武器、上衣、护腿、战靴、项链、戒指，选择已穿戴物品后可卸下。右侧展示原物品图片、收集数量、可用数量和替换前后的属性差值。C / Esc 或“继续探索”关闭。

装备使用当前已有的三套15件防具饰品及5把武器。物品必须先通过怪物掉落并靠近拾取；空行囊显示掉落指引。未拾取的装备和材料不能穿戴。每个部位只有一个栏位；替换释放旧装备，重复穿戴不会叠加。行囊收集数量包含已穿戴物品，可用数量扣除穿戴中的一件。

追归每件额外移速+3，烽炉每件额外伤害+1，镜潮每件额外减伤+1。这些单件属性与下方套装效果叠加。数值为当前可玩原型配置，仍待人工体验平衡。

[异变宝箱](fudi-chests.md)的守箱首领可掉落“异变·”品质：上述单件非零属性乘1.3后向上取整，零值不变；与普通装备单独计数，人物面板展示增强后的数值。它们保持原部位、套装归属与武器特效，不提高套装额外奖励或武器追加伤害。

伤害直接加到J斩击、K灵弹、L震荡，基础伤害为26/20/42；减伤从小怪、Boss、陷阱每次命中的伤害扣除，护盾吸收前每次至少受伤1点；护盾可将本次扣血减至0。移速加到基础260像素/秒，仍乘以陷阱减速并经过地图碰撞。生命上限仍为100。角色面板沿用已有站立图。

## 套装与武器效果

C打开装备面板，顶部“套装与特效”显示三套装备的件数、各档激活状态、全部武器规则与护盾剩余值。单件详情和悬浮说明也会显示所属套装或武器特效。属性对比会计算换装后跨越2件门槛带来的伤害、减伤、移速变化。

只有实际穿戴的同系列不同部位计数，武器和背包里的多余副本不计数；2 / 4 / 5件效果累计生效。新施放的技能使用当前冷却倍率，已有冷却不会因换装立即重算。

| 套装 | 2件 | 4件 | 5件 |
| --- | --- | --- | --- |
| 追归 | 移速+20 | J/K/L冷却缩短15% | 直接攻击命中恢复4生命，间隔1秒，不超过100；群体命中只恢复一次 |
| 烽炉 | 伤害+6 | 命中附加3秒灼烧，每秒6伤害；重复命中刷新持续时间，不叠加、不推迟下一跳 | L震荡半径+50、直接伤害再+12 |
| 镜潮 | 减伤+3 | 固定减伤后再减少20%伤害，向上取整 | 每8秒补充18护盾，刷新不叠加；初穿需等8秒，拆至不足5件即清空护盾及充能 |

| 武器 | 特殊效果 |
| --- | --- |
| 灰烬回响 | J命中后0.35秒，对该目标追加10伤害；间隔2秒 |
| 裂墟重刃 | 直接命中时目标生命≤35%，该次伤害提高60%，向上取整；阈值按命中前生命计算 |

| 坠岩重锤 | L施放后0.45秒，在施放位置按该次L半径追加18范围伤害 |

触发时显示浮字、圆环及技能下方提示；镜潮有护盾时角色周围显示蓝色护环。燃烧、回响、余震属于追加伤害，不重复触发治疗、燃烧或其他武器效果，不额外叠加直接伤害属性。它们致死仍走正常掉落结算，不重复抽取奖励。

异变品质沿用原系列的套装计数与原武器特效；其基础属性增强由品质规则提供，不额外放大这里列出的治疗、灼烧、回响、余震或护盾数值。

## 生命周期和接口

- 装备与穿戴仅保存在本轮福地内存，全部地图间保留；重新开始、离开福地后清空，不写入灵伴存档。
- 打开装备面板时，移动、攻击、冷却、首领、天气生长与陷阱均暂停；地图、行囊、对话和结算阻止叠加装备面板。
- 套装和武器特效使用探索时间，所有模态界面与结算暂停计时。换装或旅行取消遗留灼烧、减速和延迟攻击，旅行及换装清除在途灵弹；回响与治疗内置冷却不通过换装重置。旅行保留已穿戴套装、镜潮护盾和充能；不足5件镜潮时护盾立即清空。
- [属性表](../card-demo/scripts/scenes/equipment_catalog.gd)独立于共享掉落表；[面板与穿戴状态](../card-demo/scripts/scenes/fudi_equipment.gd)提供`equip_item`、`unequip_slot`、`available`、`bonuses`，由福地接入。
- [特效运行模块](../card-demo/scripts/scenes/equipment_effects.gd)负责命中、减伤/护盾、延迟伤害、减速及浮字绘制。
- 不涉及手动强化、合成、耐久、永久存档或灵伴回合战斗的装备规则；异变品质由宝箱守卫掉落提供。
