# 福地人物交流与商品购买

2026-10-21按用户要求接入已绘制的十位NPC。沿用九位定居人物与长祷者十图巡游的位置；靠近人物按E，显示对应像素人物、职责与交流/商品面板。E、Esc或“离开”关闭。交流和交易暂停探索、敌人、天气及人物巡游，地图/行囊/装备快捷键不穿透。

| 人物 | 面板与货品 |
| --- | --- |
| 路盐 | 交流与委托、木料/松脂/旧铁片、追归战靴 |
| 金算盘 | 交流与委托、细铜丝/磨石砂、追归戒指/项链；登记可交易货品，不售寄存物 |
| 洛铸 | 交流与委托、玄铁/旧铁片、烽炉胸甲/护腿 |
| 叶汀 | 交流与委托、灵草/止血草/青露叶/安息花 |
| 乔簧 | 交流与委托、细铜丝/旧铁片/凝灵石 |
| 沈衡、岑尺、谢停舟、闻昼 | 交流与委托 |
| 长祷者 | 交流与委托、独立高阶稀有货架 |

商人默认打开商品页，可切换“交流与委托”阅读已接取或已回报的现有委托。其他人物默认交流页。原地标调查与休息仍使用简短记录框，人物面板关闭后恢复原布局。

## 购买与库存

使用行囊中现有的**灵晶**按件结算；探索采集的灵晶即可使用，开局不额外赠送货币。每件列出名称、属性、价格、剩余库存，装备可悬停购买按钮查看特殊效果。不足灵晶或售罄时按钮禁用；结算时仍检查当前人物、距离、货品、库存与余额，成功才扣款并增加一件物品。买入材料放进行囊，买入装备可关闭面板后按C穿戴。

长祷者货架固定为：

| 商品 | 每件灵晶 | 每轮库存 |
| --- | --- | --- |
| 异变·棱光长刀 | 12 | 1 |
| 异变·裂墟重刃 | 12 | 1 |
| 异变·镜潮长衣 | 8 | 1 |
| 异变·镜潮戒指 | 7 | 1 |
| 凝灵石 | 4 | 2 |
| 记忆晶砂 | 3 | 3 |

高阶装备复用现有异变品质：原非零属性提高30%并向上取整，保留对应武器/套装效果。长祷者移动或玩家切换地图不会补货；各商人库存独立，重复开关窗口不补货。重开或离开福地重置购买和库存，与既有当局行囊一致，不修改灵伴存档。药草仍按现有材料用途使用。
