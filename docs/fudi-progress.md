# 福地继续探索与祝婶的灶台

2026-11-17按用户确认，完成本轮三个优先项：独立保存探索、祝婶完整地方任务、装备防御平衡。

## 保存与继续

- 从大厅或启动器进入福地，有可用存档时继续上次探索；大厅按钮显示“继续福地探索”。
- 每30秒探索时间自动保存；采集、交互、穿戴、融合、交易、人物回报及切图后合并保存。Esc菜单可手动保存，返回大厅及正常关闭窗口前也会保存。
- 保存生命、位置、各地资源与调查、守卫与首领、宝箱及守箱战、装备与融合等级、技能冷却、套装充能、天气与药圃、建筑状态、人物委托、巡游人物位置、商店库存和祝婶任务。
- 地图、行囊、对话及菜单暂停期间不计算30秒探索时间；离线不推进天气、生长或战斗。重新进入取消旧攻击预警、飞行弹及延迟伤害，保留已有血量与技能冷却，并给予1.8秒受伤保护。
- Esc菜单或失败面板选择“重新开始一轮”，确认后清空本次福地并建立新进度。死亡仍进入失败面板，读档不会自动复活。
- 保存失败会显示提示，保留当前窗口，允许重试；失败时不会自动返回大厅或正常关闭窗口。存档不可读时暂停探索并保留文件，可返回大厅或确认重新开始。

仅使用独立的 `user://fudi_expedition_v1.json`，含版本号及纯数据，不读取或写入灵伴、海上存档。先写 `.tmp` 并检查写入结果，再保留有效 `.bak`、替换主档；主档损坏时尝试备份，未来版本主档不会静默降级。普通关闭和写失败恢复经过专项验证；未进行真实断电或强杀进程的故障注入，不能保证突然断电保留最后一次写入。

## 祝婶：今天几个人吃饭

1. 在青岚灶街旧灶台按E，选择“答应帮忙”。
2. 调查街坊药圃，备齐灵草2份、木料2份，回旧灶台明确交付；不足材料或未调查时不能扣料。
3. 清除灶街普通守卫与荆冠鹿骑，调查迁灶落脚点，再回旧灶台修灶、摆好餐桌。
4. 完成时一次领取灵晶3份、追归上衣1件；灶火与汤碗出现在场景中，小地图以暖色圆点标记灶台。
5. 此后可在灶台消耗灵草1份煮热汤，恢复30生命、最高100；满血或缺药不消耗。任务、奖励、做汤次数及场景结果随存档保留。

按B的委托页查当前步骤，物品页查材料数量与用途。交谈和交料均使用暂停的原调查面板；动作需要人在旧灶台100像素内。其余NPC继续使用各自既有委托；这条地方任务不代表完整复苏系统或人物终章。

## 防御平衡

原“每点防御直接扣1点伤害”改为收益递减：防御减伤率为 `min(70%, 防御 / (防御 + 40))`。伤害先按防御折算并向上取整，再计算镜潮四件的额外20%减伤，最后由护盾吸收；护盾前至少1点伤害。面板将该属性标为“防御”并显示折算比例。

防御0/20/40/80时，20点原始伤害分别造成20/14/10/7点；五件普通镜潮全部融合+3时，防御28，16–25点首领伤害在套装减伤后仍造成8–12点，护盾另计。融合属性、消耗和套装条件沿用原规则；实际操作手感和长期经济仍需玩家试玩。
