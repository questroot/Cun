# 福地攻击、天气特效与五招首领

2026-10-21按用户要求，用pixel-art-studio绘制38组8帧像素动画并接入福地：24种首领技能、7种小怪攻击和7种天气。2026-10-28扩到56组448帧：首领补第五招共30种，新增5类玩家武器攻击与7种通用状态光环。美术源、原生图集、4倍图与GIF见 [素材说明](../pixel-art/combat-weather/README.md)，运行清单见 [manifest.json](../card-demo/assets/effects/pixel/manifest.json)，招式的提示词描述见 [prompts/](../pixel-art/combat-weather/prompts/)。

2026-11-25福地十域的56个旧特效键全部切换到 pixelfx。当前有71张96×96八帧横排图集，覆盖30招首领技能、5把武器、7种守卫攻击、7种状态、7种天气和新增的攻击、命中、投石、掉落、建筑、灶火和陷阱素材。攻击预警、范围提示和场景光圈使用 pixelfx 纹理贴合原区域。十字招式沿两轴绘制，外圈招式沿环带绘制。街道传送门独立使用[三张图集](fudi-maps.md)。灵伴回合战斗读取原状态图集。招式预警和伤害按下文的规则运行。

每张图集的效果名和源版本记录在 [pixelfx 清单](../card-demo/assets/effects/fudi-pixelfx/manifest.json)，带 `local/` 的效果由 [福地像素特效源码](../pixel-art/combat-weather/scene-pixelfx.mjs) 使用 pixelfx 绘制。素材附带上游 [MIT 许可证](../card-demo/assets/effects/fudi-pixelfx/LICENSE) 和 [署名说明](../card-demo/assets/effects/fudi-pixelfx/NOTICE.md)。从仓库根目录运行导入脚本可重建图集，最后一个参数为 [上游源码](https://github.com/patch-gg/pixelfx/tree/5294518ce7c72e48b6100a744596e0acf57f2826) 的解压目录。

```powershell
node pixel-art/combat-weather/import-pixelfx.mjs ../pixelfx
```

第五招各自沿用首领造型与调色板，但选用该首领此前未用过的预警形状，闪避方式与同形状既有招式一致。

每只按1→2→3→4→5循环，出招距离不够时先追踪。预警1.05–1.9秒、基础伤害16–25、恢复3.4–4.8秒；具体参数在 [boss_skills.gd](../card-demo/scripts/scenes/boss_skills.gd)。首招兼容原配置，原生命/落点/掉落不改。守箱首领继承对应造型的五招，沿用60%生命与逐招伤害向上取整规则；四只守箱小怪接触攻击播放阴属性特效。

预警在施放时锁定位置、朝向与全部落点，红色区域就是伤害区域：圆形/三点需走出，直线向侧面或身后移动，扇形绕到身后，十字进入夹角，环形贴近中心或离开外圈。命中与绘制复用同一几何配置，多个落点同次释放最多结算一次，并共享受伤无敌时间、装备减伤/护盾。0.70秒释放动画只负责表现，不重复伤害。M地图详情、B行囊列出五招/伤害/预警/闪避提示，附近首领栏显示正在施放的招式。

七属性普通守卫分别播放水花、叶刃、雾咒、旋风、火焰、雷击、冰刺，现改为[蓄力、投石和冲锋攻击](fudi-refinements.md)；守箱小怪继续使用接触攻击。出招时保存属性及落点，后续转天气不会中途换色。天气由润雨水线/涟漪、晴光闪芒、灵雾漂带、疾风风线/叶片、炎阳余烬、雷雨雨线/局部闪电、霜雪六角冰晶组成，沿用每75秒气候轮换；雷雨每8秒一处局部闪电，没有整屏闪白。

J 斩击使用当前武器的 `player-<武器编号>` 图集，未装备武器时用基础金色剑弧。K 释放时在手边亮起符光，灵弹核心沿实际弹道飞行并带有尾迹。棱光长刀的三向灵弹各自绘制。L 在脚下迸发紫蓝色震波。J 和 L 出手时短暂显示细线范围提示，半径取当前招式的实际值。守卫攻击特效从第一帧起播放，身体的出招姿态仍维持原有0.28秒。

普通守卫、首领和守箱怪物受到伤害时迸出定向金色火花。灵弹按飞行方向产生火花，致死时叠加散开的烟尘和倒伏残影。玩家实际扣血时，上身显示冲击火花并短暂染红，护盾完全吸收时只有护盾反馈。受击动画随游戏暂停，跨图清除。

通用状态光环为治疗、护盾、增益、灼烧、中毒、冰冻、麻痹七种，按 `status-<状态>` 取图集，与天气同为每帧120毫秒循环播放，由 `PixelVFX.draw(..., loop=true)` 绘制。回合战斗的眩晕、护盾、增伤、减攻由 `PixelVFX.status_for()` 映射到对应光环。

福地里镜潮护盾和追归回血使用各自的光环。烽炉灼烧、骨枝缚根期间，火焰和冰霜随目标移动，灼烧每跳扣血额外闪出火光，包含最后一跳。火、冰、雷属性守卫与霜典记录者造成实际伤害时，对应动画在玩家身上播放约1秒。飞石沿用出手时的属性，护盾完全吸收或受伤保护挡下时跳过动画。陷阱的孢子、地裂、电涌和薄冰会随已有减速时长显示对应效果，随机陷阱目前停用。异常动画随战斗暂停，切图清除，伤害与控制仍由原规则结算。

模态与结算暂停动画计时；旅行清空预警及战斗残留，小怪回图不播放旧攻击；死亡取消该首领剩余特效。重开重置五招轮换与所有短期状态；不写原灵伴存档，既有地图陷阱仍停用。运行代码见 [首领](../card-demo/scripts/scenes/fudi_bosses.gd)、[守箱敌人](../card-demo/scripts/scenes/fudi_chests.gd)、[天气](../card-demo/scripts/scenes/fudi_weather.gd)、[像素绘制](../card-demo/scripts/scenes/pixel_vfx.gd)。
