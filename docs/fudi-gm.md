# 福地 GM 工具

进入福地后，点击右上角 **菜单 Esc → GM · F8**，或在探索时直接按 **F8** 打开；点击关闭、按 Esc 或再次按 F8 返回探索。其他面板或结算打开时不叠加 GM；GM 打开期间，移动、战斗、天气和危险暂停。

- **加速移动**：选择1、2、3、5或10倍角色移速，1倍恢复正常；关闭面板后生效，切换地图保留倍率，入口显示当前倍率。加速沿用障碍和边界检测，不加快敌人、天气或技能冷却。
- **地图传送**：从当前十张地图中选定目标，点击“传送至所选地图出生点”。同地图也可回到出生点；复用切图清理弹道、预警与短暂无伤缓冲。地图原有采集、战斗和调查进度保留。
- **完成任务线**：选择祝婶、阿缄、温砚、陆见微或拾一，完成该人物两张地图的六处调查见闻；也可一键完成全部30处。已有进度保留，重复操作不增加记录。关闭面板后按 B 查看已完成的见闻正文。这里对应现有调查线索系统，后续人物复苏与完整结局仍待实现。

GM 操作仅在本轮福地有效，重新开始或离开后重置；不写入灵伴存档。完成人物调查不会清除敌人、触发战斗胜利或发放额外物品。玩家专用 MCP 会话保持禁用 GM。

实现在 [fudi_gm.gd](../card-demo/scripts/scenes/fudi_gm.gd)，由 [fudi.gd](../card-demo/scripts/scenes/fudi.gd) 接入移速与暂停。

运行隔离检查：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tests/fudi-gm.tests.ps1 -Render
```

检查入口会复制当前工程并使用独立测试存档，先执行 GM 专项，再执行既有福地探索回归；`-Render` 额外使用真实 OpenGL 窗口保存面板截图。测试涉及倍率实际位移、碰撞、十图安全传送、任务线幂等、见闻回看、重开重置、存档隔离与玩家桥禁用。实际结果见 [共享项目状态](../PROJECT_STATUS.md)。
