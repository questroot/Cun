# 福地地图随机陷阱

2026-10-21按用户要求暂时停用：不再生成地图陷阱、造成陷阱伤害或减速/击退，M/B显示停用状态。保留完整代码与配置，恢复时将 `trap_catalog.gd` 的 `ENABLED` 改为 `true`；下文为保留的启用规则，专项机制检查在停用期间明确跳过。首领与异变宝箱技能不受影响。

增强天气使对应陷阱的抽选权重从1变为2，并增加2点伤害；具体伤害在预警中显示，在生成时确定。随机数在每轮初始化时随机化，各地只从自己的两种陷阱中抽选。

- 每地初始随机倒计时8–14秒；每次爆发结束后再等待8–14秒，随后尝试在玩家视野内生成一处陷阱。每次最多一处，不在不可见区域偷袭。附近没有合法地点时延后2秒重试。
- 黄色圆圈先预警1.3–1.7秒，WASD走出范围即可避开；随后红圈爆发0.8–1.8秒。爆发期间进入范围仍可能被命中，每次爆发最多命中一次，沿用怪物的1秒受伤保护。没有硬控或持续中毒扣血。
- 出生点220范围、人物地标135范围、出口150范围保持安全，生成时还加上陷阱半径作为缓冲。圆圈不会覆盖这些安全点、障碍或边界。击退复用地图碰撞移动，不穿墙或出界。
- 进入地图有3秒保护。切图取消正在发生的预警/爆发、清除减速；各地倒计时与统计保留，非当前地图不推进。返回时不会重新抽取倒计时。
- 地图、人物对话、行囊、切换确认和胜负结算暂停预警、触发与减速时间；胜利后继续探索可恢复。陷阱致命伤立即显示失败/重开界面。
- 重开或离开福地清空本轮陷阱和效果，不改灵伴存档。2026-10-20随地图扩展覆盖福地十域，复用十种陷阱按区域搭配；不添加永久地形破坏、装备耐性或其他游戏的陷阱系统。

画面使用代码绘制的圆圈、蔓刺、孢子、落物、电弧、水波等原型效果，没有新导入美术。运行时对陷阱单帧时间采用与角色移动相同的0.1秒上限，避免卡顿跳过整段预警。
