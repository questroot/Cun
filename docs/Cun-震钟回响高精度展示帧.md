# Cun 震钟回响 高精度展示级 8 帧

> **结论**：按参考图（96×96 / 3500 色连续色调）的精细度重做了 8 帧展示序列，实测 6386 色、含柔光半透明像素。**这是展示级资产，不是运行图集**——运行约束（≤7 色、alpha 仅 0/255）已被刻意放开；游戏内仍用 `build.py` 的 5 色 8 帧图集。

## 一、为什么之前几版做不到

| 尝试 | 结果 | 原因 |
|---|---|---|
| 96 直绘 5 色 | 硬边平涂 | 调色板只有 7 色，无法做过渡 |
| 4× 超采样缩回 96 | 发灰发糊 | **硬边色块**放大再平均，边缘只被磨掉，没有新细节 |
| 128×128 提分辨率 | 更平滑但细节不增 | 只把同一形状画得更准，没多画东西 |
| **本版** | 连续色调、有光晕 | **在 4× 画布上直接画渐变与光晕**，再缩回 96 |

关键差别不是分辨率，是「在高分辨率上画的是渐变还是色块」。

## 四、画法要点（可复用）

1. **渐变填充**：用 numpy 生成竖向颜色 ramp，以多边形 mask 贴到 4× 画布；钟体 GOLD→BRONZE、左亮面 IVORY→PALE、右暗面 BRONZE→DARK。
2. **光晕**：把已画内容做高斯模糊（radius 2.2×4），alpha 压到 42% 后叠回，得到柔和自发光，不做硬描边。
3. **铸造细节**：两道环带（暗槽 + 上缘亮唇）、左侧镜面高光线、钟口亮顶 / 暗底、顶部提环、底部钟舌。
4. **声波**：4 层扇形环带（26°–154°），由内到外 IVORY→PALE→GOLD→COPPER 递减，逐帧向外扩散；外缘散布细小光点。
5. **命中闪光**只出现在第 3–4 帧，且放在钟口下方而非钟面上（修正了运行版里"像块补丁"的问题）。

## 五、与参考图的诚实差距

- **色调层次已达到**：连续渐变、柔光、金属明暗都与参考图同一量级。
- **结构密度仍不及**：参考图满是冰晶棱面、书页行线等密集小结构；本版主体（一口钟 + 声波）元素数量少，偏"干净的渐变"，不是"繁复的纹理"。
- 若继续逼近，需要在钟身加铆钉/铭文/锈斑、在声波里加碎波纹与更多飞散粒子，约再增 30–40 行绘制代码。
