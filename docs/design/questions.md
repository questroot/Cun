# 待决问题总表：已知的不确定性，不是一次性长问卷

状态：v0.1，**全部未决**。覆盖当前聊天、候选规划和原型接入中已识别的问题；未来新信息可能继续增加，不声称穷尽所有开发问题。当前无投票结果、无团队定案。

来源：[想法池](ideas.md)、[候选规划](project-plan.md)、[首个可玩版本](first-playable.md)。**当前使用方式改为各自交给自己的Agent讨论、总结和自己查看，不要求集中填票或回收。** [完整Agent讨论材料](agent-discussion-kit.md)已逐项补齐40题的候选、取舍与建议，并提供自包含背景和提示词；[8题简短选择表](ballot-round-1.md)仅作可选辅助。

## 三轮处理

- **第一轮 Q01–Q08：方向。** 对齐想玩什么、怎么操作、画面、模式、风险、受众和下一步交付。
- **第二轮 Q09–Q31：设计。** 第一轮结果出来后，只处理所选路线需要的世界、卡牌和远征规则；做少量样张/实验再决定，避免凭空选数值。
- **第三轮 Q32–Q40：实施与合作。** 开工前确认必要工具、文件/存档、人员、费用和验收；远期商业/联机细节允许延后。

一次只讨论一组关联问题。不是所有问题都适合多数票：风格与偏好可投票；行为是否好玩要实验；素材授权、预算和关键发布权限要由对应负责人明确确认。
