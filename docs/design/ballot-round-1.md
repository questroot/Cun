# Cun 八题简短选择表（可选辅助）

**当前主入口是[完整Agent讨论材料](agent-discussion-kit.md)：各自交给自己的Agent，自己总结、自己看，不要求统一填票或发回。** 下方保留简短选项和旧版集中汇总建议，仅在本人愿意或团队另行组织时使用，不是当前必走流程。

**这是偏好收集，不是已经启动的正式投票，也不是制作批准。** 目前没有成员回复或票数。选项无默认选中，字母顺序不表示推荐。

先看[一页讨论说明/导图](discussion-map.md)。想法可写进[奇思妙想池](ideas.md)，详细疑问见[40题问题总表](questions.md)。不用先读完全部长文档。

## 怎么填

- Q01、Q07最多选两项，并把最重要的一项写在前面；其余单选。
- 每题都允许“其他”与“暂不确定”。其他请补一句，暂不确定可以写想先看什么样张/实验。
- “喜欢某玩法”与“愿意花时间制作某玩法”分开；最后的投入问题自愿回答，不作任务承诺。
- 如果只对其中几题有意见，其余留空即可；未回答不是赞成任何方案。
- 不需要真实姓名，昵称/自定代号即可。汇总时保留原意；未经同意不把个人聊天和票单公开提交到仓库。

## Q01 最想从游戏里得到哪两种体验？（最多两项，排序）

- A：收集异灵、搭配卡牌、研究融合与构筑。
- B：探索石化世界、认识角色、追剧情和秘密。
- C：亲手操作、走位、攻击与战斗技巧。
- D：冒险搜寻，纠结继续深入还是带着收获撤离。
- E：其他，请补一句。
- F：暂不确定。

## Q02 战斗中，你希望怎样操作？（单选）

- A：战前编队布阵，开战后全自动，主要看构筑效果。
- B：单位自动行动，玩家在明确时点使用少量主角指令。
- C：回合中逐个单位选技能和目标，接近现有原型。
- D：实时操控主角攻击/闪避，异灵作为自动队友。
- E：其他。
- F：暂不确定，想先看短实验。

说明：A/B/C可以先沿用回合顺序；D需要动作与碰撞等另一套制作工作。不是禁止D，也不是把自动战斗说成一定更便宜，只是说明现有骨架的差异。

## Q03 你希望主要游玩画面是什么视角？（单选）

- A：斜俯视，能看见角色和建筑的侧面/纵深。
- B：横向侧视，横版移动与场景。
- C：正俯视，从上向下看地图。
- D：卡牌/节点选择界面为主，不做大量自由移动。
- E：其他。
- F：暂不确定，想先看同场景构图。

视角不是画风，也不决定是否真3D：斜俯视可以用2D素材实现。

## Q04 首先做哪一种画面样张？（单选）

- A：简化卡通角色/场景，科技线条与水墨动态作特色。
- B：明确的像素角色/场景，配少量适配的水墨动态。
- C：像素角色结合3D场景/灯光的HD-2D方向。
- D：其他，请描述一个最重要的视觉特征。
- E：暂不确定，希望先比较样张。

选的是先比较什么，不是授权批量美术。三种方案都需要核可读性、动作质量与制作成本，不用参考游戏的名气替代样张。

## Q05 当前候选原型需要什么模式？（单选）

- A：离线单机，先自己玩和测试。
- B：合作PvE，多人一起探索/对抗环境。
- C：PvP，有玩家之间的竞争/对抗。
- D：其他。
- E：暂不确定。

原型模式和远期愿望分开：选择单机不表示永久放弃联机。选择联机也不自动授权服务器、账号或云费用。

## Q06 失败损失能接受到什么程度？（单选，选最符合的一档）

- A：只丢当局临时增益，已获得收集物尽量保留，偏轻松。
- B：丢当局未撤离的卡牌/材料，出发前已有珍藏安全。
- C：当局战利品会丢，出发时携带的消耗品也可能损失，但珍藏卡不永久消失。
- D：连出发携带的珍藏卡也可冒险丢失，偏高风险。
- E：其他，请写哪些能丢、哪些不能丢。
- F：暂不确定，想先实际试玩。

以上是偏好档位，不是已经生效的损失合同。与存档故障、程序崩溃造成损失不是同一回事。

## Q07 最希望第一版服务哪类玩家？（最多两项，排序）

- A：喜欢卡牌组合、阵容构筑和研究规则的人。
- B：喜欢剧情、探索与收集，战斗负担希望较轻的人。
- C：喜欢操作技巧与即时战斗的人。
- D：喜欢高风险选择、失败重来和挑战的人。
- E：其他。
- F：暂不确定。

这是目标受众假设，不是市场调查结果；最终需要邀请对应玩家试玩。

## Q08 下一阶段，先交付什么来帮助大家确认？（单选）

- A：一屏视觉样张，先确认视角、画风和角色辨识。
- B：一场战斗小实验，先确认操作和构筑感觉。
- C：一次搜寻→战斗→撤离的小闭环，先确认整体玩法。
- D：一个短剧情/探索片段，先确认世界与冒险感。
- E：先讨论最关键的分歧，再决定做哪一种实验。
- F：其他。
- G：暂不确定。

这不是工期承诺；若关键前提未定，汇总后先补前提，不并行制作四种第一版。

## 收票后的建议处理方式（同样待团队认可）

1. 发起人自行约定回收时间与参与范围；本文件没有预设截止日或虚构名单。允许补充和更正。
2. 每人保留一份原答，更正覆盖自己的当前票并记录变更，不算第二人；缺席、不确定、反对单独记。
3. Q01/Q07“首选”与“次选”分开展示，不把两个选择都说成第一偏好；单选按选项计数，不先设推荐加权。
4. 跨题检查：例如想实时操作却不想承担动作制作，或想低损失却把高风险撤离列为首要体验，先询问原因，不替人改票。
5. 有明显倾向但仍有实质反对时，做低成本实验或缩小范围；投票不能宣布玩法已经有趣。
6. 制作路线由发起人与相关伙伴明确确认，记录采用范围、理由、未决项和复议条件。法律权利、费用、外发、部署和发布必须有对应授权，不能由多数偏好替代。
