| 项 | 值 |
|---|---|
| 单帧尺寸 | 96×96 px |

| 纹理内存 | 768×96×4 = 288 KiB |

三段节奏：预备 01–02 / 出手 03–04 / 收招 05–08，符合攻击类动画的 25–35 / 10–20 / 45–60 比例。包围盒逐帧从 48px 扩到 73px，扩张连续无跳变。

## 五、需要人工精修的部分（不谎报可直接商用）

- 声波外缘由径向 spokes 拼成，放大后可见细锯齿；若用于高倍率展示需手动修边。
- 第 3–4 帧的十字星落在钟面上，位置像一块补丁；建议移到钟口下方或改为钟口闪光。
- 钟体仍是程式化造型，非最终精修级商业插画。
